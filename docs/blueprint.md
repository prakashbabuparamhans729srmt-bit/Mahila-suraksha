# **App Name**: Banana Buddy

## Core Features:

- Banana Image Display: Displays various images of bananas in different contexts (e.g., banana bread, banana split, banana art).
- Banana Recipe Search: Allows users to search for banana-related recipes.
- AI Recipe Suggestion: Suggests recipes to the user. This feature could be an AI tool, using an LLM to consider the available recipes and incorporate banana content from them.

## Style Guidelines:

- Primary color: Soft yellow (#F7E7CE), reminiscent of ripe bananas, conveys a sense of warmth and freshness.
- Background color: Very light yellow (#FAF8F2), slightly desaturated, offering a clean and appetizing backdrop.
- Accent color: Pale orange (#F2C4A3), a harmonious color analogous to yellow, for interactive elements.
- Font: 'PT Sans', a humanist sans-serif font providing both a modern feel and a touch of warmth for all text elements.
- Use minimalist icons depicting bananas, cooking utensils, and related symbols with a playful style.
- A clean and user-friendly grid layout optimized for recipe presentation and image display.
- Smooth transitions when loading images or recipe details to enhance user engagement.
